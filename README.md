# 🎮 Pygame RPG Engine

> **A 2D action/RPG built with Python, Pygame, and procedural generation.**

Welcome to the Pygame RPG Engine! This is a custom engine I built to push my Python skills beyond standard web backends and into real-time rendering, procedural world generation, and game loops.

## 🕹 What is it?

This is a top-down 2D action game engine featuring a retro aesthetic. You play as a character exploring procedurally generated worlds, battling enemies with projectiles, and navigating through dynamic areas using portals.

### 🌟 Key Features
- **Procedural World Generation:** Uses Perlin noise to generate organic, non-repetitive landscapes on the fly.
- **Save/Load System:** Persistent game state management using a robust save manager.
- **Combat & Entities:** Player movement, projectile aiming, and enemy AI.
- **Dynamic Camera & Viewport:** Smooth camera tracking system for a polished feel.
- **Input Flexibility:** Native support for both Keyboard/Mouse and Joystick/Gamepad.

## 🛠 Tech Stack
- **Python 3**
- **Pygame** (Core rendering, audio, and event loop)
- **Noise** (Perlin noise for terrain generation)

## 🚀 How to Run Locally

If you want to play around with the code or just try the game, here's the setup:

1. **Clone the repo:**
   ```bash
   git clone https://github.com/ItzSaurav/pygame-rpg-engine.git
   cd pygame-rpg-engine
   ```

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(I highly recommend using a virtual environment like `venv` or `uv`)*

3. **Launch the game:**
   ```bash
   python neon_nexus/main.py
   ```
